# Сайт рекрутингу навчального батальйону КАПА

Лендинг «Продовжуй службу в тилу»: переведення з бойових посад до навчального батальйону КАПА (2-й корпус НГУ «Хартія»). Заявки та дзвінки йдуть до контакт-центру 3333.

- `index.html` — десктоп (макет 1440 px, масштабується від 1100 px до 2400 px).
- `mobile.html` — мобільна й планшет (макет 390 px, ширина до 1099 px). Сторінки перемикаються між собою за шириною вікна.
- `privacy.html` — політика конфіденційності (чернетка, див. HANDOFF.md).
- `a/` — шрифти (Khartia_023 Cond Medium, Inter Tight, Inter), фото (EXIF прибрано, неймтеги заретушовано), фавікон, OG-картинка.
- `api/lead.js` — приймає заявку з форми й пересилає на `LEAD_WEBHOOK_URL`. Поки змінну не задано, відповідає 503, і форма показує стан помилки з підказкою телефонувати 3333.

Без збирання: Vercel віддає файли як є. Поки сайт закрито від пошуковиків (`noindex`, `robots.txt`).

Джерело дизайну — полотно Claude Design, варіант A: https://claude.ai/artifact/KWwUr4ca76fBtQNQjm7eSe (артборди KapaA, KapaA-Modal, KapaA-Mobile). Тексти — ТЗ у Figma H4gB4QwQIydcGiViRPSPGn.

Перевірка вручну: десктоп 1440/1280/1920, мобільна 390/360, планшет 768; вікна напрямів (кнопка, Escape, клік поза вікном), «подати заявку» з вікна переносить напрям у форму; помилки полів, надсилання, успіх і помилка сервера.
